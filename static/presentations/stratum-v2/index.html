Mining · Stratum V2

MARA mines its first Stratum V2 block

Block 975,369 was mined with Stratum V2 on 2026-11-10, making MARA one of the first industrial miners to do so. What does SV2 change, and what does it change for a solo pool?

Sources: MARA Foundation, "Why MARA Is Upgrading to Stratum V2" · SV2 spec · sv2blocks.com

Today: Stratum V1 (2012)

Every machine talks plaintext JSON to the pool

The spec's own motivation: V1 "is JSON-based and lacks cryptographic authentication, making it slower, heavier, and less secure."

Stratum V2

One encrypted link per site, binary messages

Encryption is mandatory for remote links and optional on the LAN. The server authenticates with a secp256k1 key (BIP340 signatures, BIP324-style ElligatorSwift handshake).

Under the hood

Three sub-protocols, one framing

Mining Protocol

The V1 successor; always used. Standard channels give devices header-only mining: no coinbase or Merkle work on the ASIC, 256 hashes per job per nTime (about 72 PH/s). Extended and group channels let proxies split the work.

Job Declaration

Optional. A farm's JD Client declares its own block template to the pool's JD Server. One declaration serves every device, on separate infrastructure from share submission.

Template Distribution

Replaces getblocktemplate polling. The Template Provider pushes a new template on a new tip or when fees rise enough. Usually Bitcoin Core.

  • Bitcoin Core 30.0 added an experimental IPC mining interface (bitcoin -m node -ipcbind=unix). The separate sv2-tp app (v1.1.3, Nov 11) turns it into an SV2 Template Provider, and now needs Core 31.0+.

Decentralization

Who chooses the transactions?

Job Declaration is where SV2's decentralization lives: it lets hashers in a public pool pick transactions. MARA is a vertically integrated solo miner, so its gains are operational.

MARA's reasons

Latency, bandwidth, security

Latency

Nodes run on-site, so machines don't each talk to MARA Pool over the internet to get work.

Bandwidth

Compact binary messages. The site-local JD node becomes "the singular connection to the pool," replacing tens of thousands of miner connections.

Security

Encrypted site-to-pool links close V1's man-in-the-middle hashrate hijacking risk.

  • Job Declaration isn't fully used yet. MARA plans to integrate it so individual sites can build blocks locally, for latency and bandwidth.
  • MARA is a member of the Stratum V2 Working Group, alongside AntPool, Braiins, Block, F2Pool, Foundry, Mempool.space, Spiral and others.

sv2blocks.com

9 SV2 blocks so far: 0.04% of all blocks

How it detects SV2

MARA's blocks carry an Sv2/MARA coinbase tag. DMND's block (tagged /DMND/) was added by hand. The protocol itself isn't visible on-chain.

So it's a floor

Any SV2 block without a recognizable tag is counted as "other." Data as of 2026-11-25 00:30 UTC, tip 977,443.

Discussion

Questions for the room

  • Does SV2 adoption by solo miners help decentralization at all, or is it purely an efficiency upgrade?
  • What would get public pools to turn on Job Declaration for their hashers? Is it fees, liability, or something else?
  • With 0.04% of blocks, is SV2 still a niche? What's the real blocker: firmware, pools, or Bitcoin Core's IPC interface still being experimental?
  • sv2blocks relies on coinbase tags. Should SV2 pools tag their blocks so adoption can be measured?
  • Would you run a Template Provider at home and point a small miner at a public pool with Job Declaration?
